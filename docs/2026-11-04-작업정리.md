### 주요 기능
- **캐릭터**: 연료·배터리 → 배고픔, 경고등 → 아픔, 주행량 → 피로. 표정 7종이 차 상태에 따라 바뀜
- **오늘의 일기**: 하차하면 캐릭터가 그날 운전을 일기로 써 줌
- **성장**: 운전·정비·충전으로 경험치 → 레벨업 → 선글라스·꽃·리본·캡·왕관 해금
- **AI 음성봇**: "기분 어때?", "얼마나 갈 수 있어?", "어디 아파?", "어디 주차했어?" 등에 목소리로 대답
- **현대 Open API**: 차량 목록 API 문서 확인 완료, 로그인·토큰 교환·API 중계 서버 구현

### 보안
- 현대 Client ID/Secret, 토큰, Typecast 키는 `.env.local`에만 있고 **GitHub·배포본 어디에도 없음** (전체 커밋 기록 검사 완료)
- 배포할 때마다 키 포함 여부를 자동 검사, 포함되면 배포 중단

## ⏳ 남은 일

### 직접 하실 일
1. **Typecast 가입 → API 키 발급** (typecast.ai → API Console). `.env.local`의 `TYPECAST_API_KEY=` 뒤에 넣고 저장
   - 무료: 월 1만 5천 자 (질문 약 200번). 무료분은 상업적 사용 불가 · 출처 표시 필요
   - 아이 목소리는 PC에서 `npm run dev`로 실행할 때 동작. 배포 링크는 브라우저 목소리 사용
2. **공모전 1차 서류 양식** (제출 양식·분량·심사 기준·마감일) 공고문에서 복사해 주기
3. 휴대폰 마이크로 말 걸기 직접 테스트 (배포 링크에서 가능)

### 제가 할 일
1. **1차 서류(기획서) 작성** — 양식 받으면 바로. 컨셉, 핵심 루프, API↔캐릭터 매핑표, 화면, 구현 현황(체험 링크) 포함
2. Typecast 키가 들어오면 실제 아이 목소리 테스트·목소리 고르기
3. 현대 API: 상태 API 문서(주행거리·배터리·경고등·주차) 받으면 주소 맞추고 실제 차로 테스트

### 나중에
- Figma 디자인을 블랙+실버로 마저 반영 (Figma 무료 플랜 호출 한도 때문에 색 변수만 바뀐 상태)
- 배포 링크에서도 아이 목소리 쓰기 (무료 서버 Cloudflare Workers 등 필요)
